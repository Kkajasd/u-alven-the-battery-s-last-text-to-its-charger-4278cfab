The phone battery's last text message to the charger it waited for all day, as one line of plain text of at most 200 characters. A judge model reads lines two at a time and keeps the funnier one, round after round.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`.
